# Store Listing Screenshots

PNGs in this directory are generated by the integration tests via
`test_driver/screenshot_driver.dart` and uploaded to App Store Connect / Google
Play Console as marketing screenshots.

## Generating

Boot the device whose screen size you want to ship (e.g. iPhone 15 Pro Max for
the App Store 6.7" set, or a Pixel 7 Pro emulator for Play Store 6.7"), then:

```sh
# Run a single test file's screenshots
flutter drive \
  --driver=test_driver/screenshot_driver.dart \
  --target=integration_test/main_flow_test.dart

# Or all of them in sequence (bash)
for f in integration_test/main_flow_test.dart \
         integration_test/home_page_mark_as_read_test.dart \
         integration_test/streak_validation_test.dart \
         integration_test/bible_mastery_achievement_test.dart \
         integration_test/seasonal_challenge_journey_test.dart \
         integration_test/social_engagement_journey_test.dart \
         integration_test/group_collaboration_journey_test.dart \
         integration_test/friendship_social_journey_test.dart; do
  flutter drive --driver=test_driver/screenshot_driver.dart --target=$f
done
```

For the Play Store three-form-factor sweep, use `scripts/capture_play_store.sh`.

PNGs land in `screenshots/<NN_name>.png`. Filenames are zero-padded so a
filesystem sort matches the recommended store-listing order.

## Notes

- Running `flutter test integration_test/` (no driver) still passes — the
  helper's `takeScreenshot` is a no-op when no driver is attached.
- Status bars / device frames can be added later with `fastlane frameit`.
